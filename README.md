# 👻 Ghost Stories - True or False?

A web app that tells harrowing tales and challenges you to determine if they're based on real events or pure fiction.

## Features

- 📖 **Harrowing Tales**: Read spine-chilling stories from around the world
- ❓ **True or False**: Decide if each story is based on real events or fabricated
- ✅ **Instant Feedback**: Find out immediately if your guess was correct
- 📚 **Real Story Details**: When a story is true, learn the fascinating real-world details
- 🎯 **Score Tracking**: Keep track of consecutive correct answers
- 🔄 **Continuous Play**: Move on to the next story and keep playing

## How to Play

1. Open `index.html` in your web browser
2. Read the harrowing tale presented
3. Decide if you believe it's TRUE or FALSE
4. Click your answer
5. See if you were correct and learn the real details (if it's a true story)
6. Click "Next Story" to continue
7. Try to build up your consecutive correct score!

## Running the App

Simply open the `index.html` file in any modern web browser. No server or installation required!

Alternatively, you can serve it with a local server:
```bash
# Using Python
python3 -m http.server 8080

# Then open http://localhost:8080 in your browser
```
